# Nova Mobile

A Lunar-style companion app for Minecraft Java on Android, made for a Galaxy Note 10+ (SM-N975F) but works on any phone.

- **Play**: pick a version (including 26.1 and 26.2), see the settings to enter in your launcher, open Zalith/Pojav/your launcher.
- **Controls**: multi-select buttons, then choose who a change applies to: selected only, all except selected, or everyone. Drag one selected button to move the whole group.
- **Mod AI**: an offline advisor that reads your phone's model and RAM and suggests mods and settings.

Nova Mobile does **not** run Minecraft itself. It opens a launcher you install separately.

## Get the APK with no PC (GitHub only)
1. Create a new GitHub repository.
2. Upload everything from this zip (keep the folders, including `.github`).
3. Open the **Actions** tab, run **Build APK** (or just push).
4. When it finishes, open the run and download `nova-mobile-debug-apk`. Unzip it and install the APK.

The project has not been compiled by its author. If the build fails, open the failed step in Actions and send me the error text.
